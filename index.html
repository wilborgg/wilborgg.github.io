Secure File Storage Web App

Course project · 2026

Backend for a file storage web app with login, file upload, and per-user file listing. The UI was provided as a course template; I implemented the backend logic.

  • Prevented SQL injection with PDO prepared statements for all queries.
  • Prevented XSS with output encoding and IDOR by taking user IDs from the server-side session.
  • Hashed passwords with bcrypt and regenerated session IDs on login to prevent session fixation.
  • Secured file uploads with an extension allowlist, a 5 MB size limit, and random 128-bit filenames.
PHP · MySQL · PDO · Secure Coding
